# Recovery software comparative benchmark methodology

## Evaluated tools

* **AI Seed Phrase Finder:** Enterprise supercomputing cluster solution.
* **BitResurrector v3.0.3:** Monolithic native Windows C++/ASM application with local Bloom filter.
* **BTCRecover:** Open-source Python command-line utility.
* **BIP39-Recoverer (Coinplate):** Lightweight browser-based JavaScript tool.
* **Seed Saviour (ZenGo-X):** Single-page browser-based recovery script.
* **Profanity / Hashcat:** Raw GPU private key search utilities.

## Benchmark scoring criteria

1. Setup simplicity and host isolation (0 to 20 points).
2. Missing word recovery capability (0 to 25 points).
3. Permutation and geometric ambiguity handling (0 to 20 points).
4. Address balance discovery without known target (0 to 20 points).
5. Computational throughput on consumer hardware (0 to 15 points).

# Contributing guidelines

We welcome contributions to the open-source CLI utilities, documentation, and automated test suites of bitResurrector.

## How to contribute

1. Fork the repository on GitHub.
2. Create a feature branch: `git checkout -b feature/improved-checksum`.
3. Ensure all Python tools adhere to PEP 8 standards and pass unit tests.
4. Run unit tests locally: `pytest tests/`.
5. Submit a descriptive Pull Request against the `main` branch.

## Scope of contributions

This repository contains the open-source specification, developer tools, and verification framework. Pull requests enhancing CLI utilities, test coverage, and documentation are prioritized.
